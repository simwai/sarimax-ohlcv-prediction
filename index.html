My Trading Chart

About this chart

This chart displays trading data fetched from a CSV file hosted on GitHub. It uses Plotly.js to create an interactive candlestick chart. Here's a breakdown of what's happening:

  • Data Fetching: When the page loads, the JavaScript code fetches data from a CSV file hosted on GitHub. This data includes timestamps, open prices, high prices, low prices, close prices, and volumes for each trading period.
  • Chart Creation: The fetched data is used to create a candlestick chart using Plotly.js. A candlestick chart is a style of financial chart used to describe price movements of a security, derivative, or currency. Each "candlestick" typically shows one day, thus a one-month chart may show the 20 trading days as 20 candlesticks.
  • Interactivity: The chart is interactive. You can zoom in and out, hover over data points to see more information, and pan across the chart.
  • Responsiveness: The website is built using Bulma CSS, a modern CSS framework based on Flexbox. This makes the website responsive, meaning it adjusts its layout and functionality based on the size of the user's screen.
  • Help Modal: This is the help modal! It provides more information about the chart and the website. You can open it by clicking the "Help" button, and close it by clicking the "X" button in the top right corner.
